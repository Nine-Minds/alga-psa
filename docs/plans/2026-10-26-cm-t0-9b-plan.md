# CM T0-9b: Content: project status and ordering

> Provenance: the Design Session plan was not found on disk, so this charter is
> reconstructed from the work order's binding decisions (C4, C5, C6, S4).

## Goal
Port the Co-Managed branch's project status and ordering fixes to main as one
standalone change. No feature flag, capability or migration.

## Outcomes
- Swapping two project statuses or two tasks never trips a unique-index collision.
- No server action calls another server action.
- The unauthenticated ordering endpoints are gone.
- Project events publish only after their transaction commits.

## Scope and decisions
- **C4** (`projectTaskStatusActions.ts`): `reorderTenantProjectStatuses` takes a
  tenant advisory lock, renumbers in two phases (temporary range, then final
  values), and validates the input set against the tenant's statuses.
  `deleteProjectStatusMapping` rejects out-of-scope replacements and resolves the
  replacement by semantic key first.
- **C5**: `reorderPhase` and `reorderTask` no longer call other actions. Repair and
  regenerate run in the same transaction. A cross-phase neighbour is an error.
  New plain helpers in `packages/projects/src/services/projectOrderingService.ts`
  (no `'use server'`). `server/src/lib/services/orderingService.ts` keeps its key
  generator; only the static bypass methods are removed.
- **S4**: delete `packages/projects/src/lib/orderingService.ts`; fix the one
  line in `projectUtilityTenantScoped.contract.test.ts` that this breaks; amend
  the T0-9b manifest.
- **C6**: publish events via `registerAfterCommit` in `projectActions.ts`
  (PROJECT_CREATED), `projectTaskActions.ts` and `ProjectService.ts`. ProjectService
  threads `getDbForContext` and runs the delete existence probe in the transaction.
  Out of scope (known remaining sites): `taskCommentService`, KB, `updateTicket`.

## Constraints
- Re-cut by path, 3-way merges for files main has changed.
- Keep main's `getProjectTreeData` self-heal.
- Strip all co-managed coupling. No drive-by refactors, flags or option bags.
- Do not commit `package-lock.json`. Nothing pushed, no PR.

## Tests
1. `regenerateOrderKeysTenantScoped.contract.test.ts` updated.
2. Swap tests (status swap, task swap, cross-phase neighbour rejected).
3. After-commit event test (rollback publishes nothing, commit publishes once).
4. `projectUtilityTenantScoped` contract test, plus no `'use server'` ordering endpoint.
5. Red/green proof against main.
