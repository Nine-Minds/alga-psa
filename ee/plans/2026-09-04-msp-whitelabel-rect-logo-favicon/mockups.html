Enterprise only, behind the existing “Enable MSP UI customization” switch. The square mark keeps every circular frame working; the new wide logo only paints the expanded rail, where an MSP wordmark can carry its own name. Nothing here changes Community.

A is the new state: a wide logo with the MSP name baked in, rendered at natural width, object-contain, no circular crop and no duplicate name span next to it. B is today’s look, which stays the fallback whenever no wide logo is uploaded. C is stock AlgaPSA (no white-label), unchanged.

2 · Collapsed rail (4rem) — always the square mark

A 200×32 wordmark cannot survive a 4rem rail, so the collapsed state never renders the wide logo: it always uses the square mark (or the stock Alga mark when no square mark was uploaded). This is why the settings card keeps calling the first slot the square mark and treats it as the required one — the wide logo is an optional extra, never a replacement.

2b · Light rail (custom theme) — the variant follows the background

Every shipped theme paints a dark rail, but the custom theme editor exposes “Side panel background” per mode, so a tenant can make it pale. The rail therefore measures the colour it actually painted instead of assuming: light rail → wide / default first, dark rail → wide-dark / dark first, and the dark-first order stays whenever the colour cannot be read. Muted chrome (mark frame, section headings, version and attribution rows) comes from the sidebar-text token for the same reason.

Rail background read at runtime, not assumed Relative luminance decides, so mid-greys land somewhere sensible Unreadable colour → dark-first, i.e. today's behaviour

3 · “Powered by AlgaPSA” footer row

Sits directly under the existing release-notes version link, inside the same bordered block. It only appears for white-labeled tenants — an un-branded tenant already says AlgaPSA at the top of the rail, so a second line would be noise. The tiny Alga mark links to the release notes with the exact version in its tooltip. GitHub star button: hidden while white-labeled (an MSP-branded rail should not advertise our repository to their staff); it returns the moment white-labeling is switched off.

The two existing slots are renamed to Square mark (light / dark). Two optional Wide logo slots and one Favicon slot join them.
